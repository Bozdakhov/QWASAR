## Task

The my_initializer function takes a pointer to an integer as its parameter param_1. 
The * operator is used to dereference the pointer and access the value stored at the memory location pointed to by param_1. 
This value is set to 0 by assigning 0 to *param_1.

## Description

The my_initializer function takes a pointer to an integer as its parameter param_1. 
The * operator is used to dereference the pointer and access the value stored at the memory location pointed to by param_1. 
This value is set to 0 by assigning 0 to *param_1. ptr

## Installation

In the main function, we declare an integer variable variable_a and initialize it to 12. We then print the value of variable_a, which should be 12. 
Next, we call the my_initializer function with the address of variable_a passed as an argument using the & operator. Finally, we print the value of variable_a again, 
which should now be 0 because we have updated its value using the my_initializer function.
