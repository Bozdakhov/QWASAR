## Task

The function first checks if the first string param_1 is an empty string. If so, it returns 1 because an empty string is always hidden in any string. 
Otherwise, it iterates through the second string param_2 and checks if each character in param_1 is present in param_2 in the same order. 
If all characters in param_1 are found, it returns 1, otherwise it returns 0.
This is the main loop that iterates through the second string param_2 and checks if each character in param_1 is present in param_2 in the same order.
The loop continues as long as param_2 points to a non-null character (i.e., a character that is not the end-of-string character '\0').
Inside the loop, the function compares the character pointed to by param_1 with the character pointed to by param_2. 
If they match, param_1 is incremented to check the next character in param_1. If param_1 reaches the end of the string (i.e., points to the null character '\0'), 
it means that all characters in param_1 have been found in the same order in param_2, and the function returns 1.
If the characters don't match, or if param_1 has not yet reached the end of the string, param_2 is incremented to check the next character in param_2.

The function returns a pointer to a string_array structure, which contains an array of strings and the size of the array.

Finally, the function returns a pointer to the string_array structure. Note that the input string is not modified by the function.

The function returns a pointer to a dynamically allocated string_array structure that contains an array of strings.
The function first calculates the lengths of the input string and the separator string. 
It then counts the number of substrings that will be generated by counting the number of separator characters in the input string.
The function then allocates memory for the string_array structure and the array of strings, based on the number of substrings. 
It then iterates over the input string, looking for separator characters. When it finds a separator character, 
it calculates the length of the substring between the previous separator character and the current one, 
and copies that substring into a new dynamically allocated string in the array. If there are no more separator characters, 
it copies the remainder of the input string into the final string in the array.
After all the strings have been allocated and copied, the function returns a pointer to the string_array structure. 
Note that the caller is responsible for freeing the memory allocated by the function.
