## 
Readme.so is a simple online drag and drop editor that can help you quickly create the README file for your data science 
project in a short period of time with its easy interface. 
The tool was developed by Katherine Peterson and it’s also completely free for anyone to use and create the readme file.



## 
This panel is located in the middle of the editor page. It will show the content of the sections you have selected for your readme file. 
This is the only place where you can edit/modify the content based on your data science project.
