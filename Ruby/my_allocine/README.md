## Task

This project involves working with SQL, a programming language used to manage relational databases and perform various operations on data in them. 
The project provides a database containing multiple tables related to the movie industry, such as actors, genres, directors, movies, reviews, and their relationships. 
The project aims to write SQL requests to retrieve specific information from the tables.
To get started with the project, one needs to download the database file named "movies.db" using the provided link. One can then connect to the database using SQLite3, 
a lightweight database engine. The project provides a Ruby file named "my_allocine.rb," where one can write SQL requests to retrieve the required information from the database.
The project provides a set of SQL requests, starting with simple ones like displaying all actors and genres to more complex ones. 
Like finding the actors who played a role in the movie "Annie Hall" and their respective roles. The SQL requests involve using keywords like SELECT, FROM, JOIN, WHERE, and ORDER BY. 
Some SQL requests involve using subqueries and joining multiple tables to retrieve the desired information.
One can run the SQL requests using SQLite3 and the database file to see the output. The SQL requests have a semicolon at the end, indicating the end of the statement. 
The project aims to help improve one's SQL skills and familiarize oneself with working with databases and their relationships.

## Installation

Sure! SQL (Structured Query Language), as mentioned earlier, is a standard programming language used to manage relational databases and perform various operations on data in them. 
It is widely used by database administrators, developers, and data analysts to manage and manipulate data in databases. 
SQL is used to create, read, update, and delete (CRUD) data in databases and to perform various operations like joining tables, filtering data, and aggregating data.
Relational databases store data in tables with columns and rows, where each column represents a category of data, and each row contains a data value for the intersecting column. 
The tables are related to each other through relationships, such as one-to-one, one-to-many, and many-to-many. 
SQL provides various commands to manipulate data in tables and to retrieve data from them based on certain conditions.
The movie industry database used in the project contains multiple tables, such as actors, genres, directors, movies, and reviews, and their relationships. 
Each table contains specific information related to the movie industry, and the relationships between the tables allow us to retrieve more complex information by joining them.
For example, to find the actors who played a role in the movie "Annie Hall" and their respective roles, we need to join the "actors" table with the "movies_actors" and "movies" 
tables using their respective IDs. We then filter the results based on the movie title "Annie Hall" to get the desired output.
The project helps to improve one's SQL skills by providing a set of SQL requests with varying levels of complexity. 
It also helps to familiarize oneself with working with databases and their relationships, which is an essential skill for data analysts and developers.
